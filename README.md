## Visão Geral

O **SustentaMed** é uma plataforma desenvolvida para gerenciar o ciclo de doação, controle de estoque e redistribuição comunitária de medicamentos não vencidos mas próximo ao prazo. O sistema conecta as UBS entre si para esta redistribuição entre elas, evitando o descarte inadequado de fármacos no meio ambiente e promovendo o acesso gratuito a medicamentos para populações vulneráveis.

## 🎯 Objetivos e Problema Resolvido

* **Problema:** O descarte incorreto de medicamentos gera poluição hídrica e do solo, enquanto milhares de pessoas deixam de realizar tratamentos por falta de condições financeiras.
* **Solução:** Um sistema centralizado de controle de lote, validade e triagem de medicamentos doados, garantindo segurança sanitária e distribuição ágil.
